## 1. 一句话目标

**一个能在浏览器里看到所有 ADB 设备、能挑脚本在指定设备上跑、能实时看到每台设备日志、能切换查看视角的本地小工具。**

---

## 2. 4 个用户故事(对应 4 个能力,也是验收标准)

| 编号 | 故事 | 实现要点 |
|---|---|---|
| **US-1** | 我能在前端看到当前已连接的所有 ADB 设备 | 自动每 3s 刷新 + 手动刷新按钮;显示:`序列号 / 状态(online/offline) / 型号` |
| **US-2** | 我能在前端看到 scripts/ 下所有脚本,点一个按钮就能在指定设备上跑指定脚本 | 脚本列表 + 每行"运行"按钮(可下拉选设备);启动后状态切换为 running |
| **US-3** | 设备跑脚本时,前端的"日志控制台"实时显示该设备的标准输出 | WebSocket 逐行推送,延迟 < 500ms;点其他设备可切换查看 |
| **US-4** | 我能看到每台设备 × 每个脚本的运行状态:开始时间、结束时间、运行中/中断中/空闲中/已完成/已失败 | 状态机:`idle → running → (finished\|failed)`;支持"中断"按钮触发 `interrupting → interrupted` |

---

## 3. 显式不做(Out of Scope)

为防止范围蔓延,以下功能**本期不做**:

- ❌ 报告生成(HTML/MD/PDF)
- ❌ 历史日志检索/导出
- ❌ 多用户/鉴权
- ❌ 插件框架/参数 schema 校验
- ❌ 脚本版本管理、收藏、预设、编排
- ❌ 设备分组/标签
- ❌ 任务调度/定时执行
- ❌ Docker 部署(直接 start.bat)
- ❌ 跨平台(Linux/macOS) —— **首版只支持 Windows**(用户实际环境)

---

## 4. 验收标准(DoD)

逐条勾选,全过即发布:

- [ ] 双击 `start.bat` 后浏览器自动打开 `http://127.0.0.1:8000`
- [ ] 设备列表每 3s 自动刷新,显示已连 ADB 设备序列号和状态
- [ ] 脚本列表显示 `scripts/*.py` 下所有脚本
- [ ] 选 1 台设备 + 1 个脚本 → 点"运行" → 该设备状态变 running,开始时间显示
- [ ] 脚本里 `print()` 的内容 500ms 内出现在日志控制台
- [ ] 切换到其他设备的日志面板,显示该设备的输出
- [ ] 任务运行中点"中断" → 状态变 interrupted,子进程被 kill
- [ ] 脚本自然结束 → 状态变 finished(成功)/ failed(非零退出码),显示结束时间和耗时
- [ ] 单设备/单脚本故障不影响其他任务
- [ ] 关闭再启动服务后,内存中的任务状态可以重建(可选:从 `data/tasks.json` 恢复)
